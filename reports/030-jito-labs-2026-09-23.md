## Job Description (archived verbatim)

Posted: 10 Hours Ago

Senior Frontend Engineer - JTX — Jito Labs

Location: Remote (Hiring Remotely in United States)
Salary: $185K-$215K Annually

About Jito

Jito builds market infrastructure for Solana, including validator infrastructure, BAM framework, JitoSOL (liquid staking token), and JTX trading application. The company operates as a lean, high-density team where engineers own significant surface area.

Role Overview

This position involves expanding JTX's web and mobile trading client. The candidate would be the third frontend engineer on a two-person team that built the existing platform. Focus areas include order books, charts, order entry, positions, execution visibility, wallet flows, and onboarding.

Key Responsibilities
- Build real-time trading interfaces handling streaming market data
- Optimize for low-latency performance and render budgets
- Develop wallet and signing flows for self-custodial and embedded wallets
- Maintain shared component and state layers
- Make architectural decisions for platform scaling
- Ship rapidly while iterating based on user feedback

Current Challenges

The team identifies several hard problems: data freshness across WebSocket streams, maintaining performance with constant updates, security for wallet signing and session auth, shipping volume with a small team, cross-platform consistency between web and mobile, and making execution quality transparent to users.

Technical Stack

React 19 + TypeScript on Next.js. Jotai + TanStack Query. Tailwind with a token-based design system. TradingView Advanced Charts on our own datafeed. Privy wallets. WebSockets to our engine.

Required Qualifications
- 5+ years building production frontend with real-time, data-dense, or financial applications
- Deep expertise in React and TypeScript
- Mobile experience with React Native, Expo, or native iOS/Android
- Strong browser performance and WebSocket fundamentals
- Security-first approach to signing flows and key handling
- Ability to refactor and ship simultaneously in live codebases

Preferred Background

Experience with trading terminals, consumer fintech, charting/visualization, Solana/EVM development, or maintaining TypeScript libraries.

Work Culture

The organization emphasizes remote-first operations, transparent communication, ownership, humility, and rapid execution. "Small egos, high standards" characterizes the environment.
