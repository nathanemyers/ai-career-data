## Job Description (archived verbatim)

Posted: An Hour Ago (also displayed as "Reposted An Hour Ago")

**Job Title:** Frontend Developer (Fiori + UI5)
**Location:** Remote
**Compensation:** 1M-2M Annually (as displayed by Built In — see Block D/G for a plausibility note)
**Seniority:** Senior level

**Job Description:**
We are seeking an experienced Frontend Developer with strong hands-on expertise in SAP UI5 and SAP Fiori to support our ongoing and upcoming projects. The ideal candidate will be responsible for designing, developing, and enhancing intuitive, high-performing user interfaces for SAP-based applications.

**Key Responsibilities:**
- Develop and enhance custom SAP Fiori/UI5 applications for enterprise-grade projects.
- Work on the SAP Fiori Launchpad including tile/catalog/group configuration, role assignment, and theming.
- Integrate frontend apps with OData services for real-time data consumption from SAP backend systems.
- Collaborate with functional and backend teams to gather requirements and translate them into technical specs.
- Conduct UI debugging and performance optimization for web-based SAP applications.
- Extend standard Fiori apps and develop custom applications using MVC architecture in SAPUI5.
- Participate in code reviews, unit testing, and troubleshooting.
- Document technical specifications and application design as needed.

**Must-Have Qualifications:**
- 5+ years of hands-on experience in SAP UI5 and Fiori frontend development.
- Strong command of HTML5, CSS3, JavaScript, and jQuery in the context of SAPUI5.
- Proven experience with OData service integration in UI5 applications.
- Deep understanding of Fiori app architecture, design guidelines, and responsive UI development.
- Experience with custom and standard Fiori app configuration on the Launchpad.
- Familiarity with tools like SAP Web IDE, BAS (Business Application Studio), and Eclipse.
- Ability to work independently in a remote environment and coordinate with global teams.
